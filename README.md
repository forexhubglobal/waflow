# WAFlow

WAFlow is a Multi-Tenant SaaS Platform for WhatsApp Sales CRM and AI Sales Assistant.

## Product Overview
Target Market: Malaysia → SEA (Initial niche: Contractors / renovation companies)
Business model: Monthly subscription SaaS

### Core Principles
- Web-based SaaS
- Multi-tenant
- Role-based access
- Responsive desktop/tablet/mobile web
- API-first architecture
- Official WhatsApp Business Platform integration
- Secure customer data isolation
- Subscription-based billing

## Tech Stack
- **Frontend**: Next.js (App Router), React, Tailwind CSS
- **Backend**: NestJS, Node.js
- **Database**: PostgreSQL (Prisma ORM)
- **Infrastructure**: AWS (recommended), Redis for cache/queue

## Project Structure
- `/frontend` - Next.js web application
- `/backend` - NestJS API application

## Getting Started

### Prerequisites
- Node.js (v18+)
- PostgreSQL database
- Redis (optional for local dev, required for prod)

### Development
1. Clone the repository
2. In `/frontend`, run `npm run dev`
3. In `/backend`, run `npm run start:dev`
